# Med101 Answer Key PDFs

Upload the subject answer-key PDF files into this folder.

Suggested filenames (use these exact names where possible):
- `anatomy.pdf`
- `physiology.pdf`
- `biochemistry.pdf`
- `histology.pdf`
- `microbiology.pdf`
- `pathology.pdf`

After uploading, the files will be available at `https://med101.space/answer-keys/<filename>` once the Vercel deployment finishes.

To upload: open this folder on GitHub, choose **Add file → Upload files**, select your PDFs, and commit the changes to the `react-rebuild` branch.
